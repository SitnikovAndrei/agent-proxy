## Поведение до изменения и соответствие переносу

| Обязанность | sing-box и прежний путь | Текущий путь |
| --- | --- | --- |
| OCM API key | OpenAI `/v1/...`, серверный bearer | Сохранено |
| OCM OAuth | Codex backend, удаление `/v1`, запрет chat completions | Сохранено |
| Query и клиентские заголовки | Передача query, User-Agent, originator, beta и остальных заголовков; конфиг заменяет одноимённые | Query сохранён; в OCM клиентские заголовки ограничены списком из README по запросу пользователя, Cookie удаляется; явно настроенные заголовки сохраняются |
| `client_version` | sing-box передаёт полученный query; сам Codex добавляет версию | Для OAuth GET `/v1/models` добавляется документированная версия, только если параметр отсутствует |
| Каталог моделей | Прозрачный ответ Codex `{models: [...]}` | Исходный `models[]` сохранён без изменения полей; добавлены OpenAI `object` и минимальный `data` (`id`, `object`, `created`, `owned_by`); ETag преобразованного ответа удалён |
| Серверные credentials | Замена bearer, установка account ID при наличии | Сохранено; чужой account ID теперь удаляется и при отсутствии серверного |
| OCM refresh | Отсутствующий last_refresh или возраст 8 дней, запись credentials | Сохранено, добавлены отмена, таймаут и перечитывание файла |
| OCM HTTP/SSE/WebSocket | Передача ответов, usage и rate-limit заголовков | Сохранено; HTTP и WebSocket используют одну сборку заголовков |
| CCM OAuth | Anthropic bearer и OAuth beta, остальные beta клиента | Сохранено; OAuth beta гарантируется после применения конфигурации |
| CCM версия API | Входящий `Anthropic-Version` передаётся | Сохранено; дополнительного обязательного заголовка версии в sing-box нет |
| CCM refresh | Обновление за минуту до истечения, сохранение credentials | Сохранено |
| Usage и тарифы | Разбор обычных и потоковых ответов, модели, кэш, service tier | Сохранено; запись перенесена в SQLite по запросу пользователя |

## Исправления по результатам сверки

Причина 400 `/models` — отсутствие адаптации для клиента без `client_version`.
В sing-box автоматической подстановки тоже нет. Параметр добавляет клиент Codex.
Дополнительно устранена несовместимость формата каталога с OpenAI-клиентами.

При замене пути формирования заголовков сохранены: заголовки клиента,
конфигурационные замены, серверная авторизация, account ID и регенерация
WebSocket handshake библиотекой. Добавлено удаление `X-Api-Key`, чужого
account ID и заголовков из `Connection`, включая конфигурационные значения.
Локальная авторизация перенесена перед чтением credentials и refresh.
Ошибки HTTP-соединений больше не возвращают клиенту URL с query.

## Осознанные отличия и ограничения

- detour и транспорт sing-box заменены прямыми соединениями стандартной библиотеки;
- реализован файловый TLS; дополнительные режимы TLS sing-box не перенесены;
- CCM не читает macOS Keychain: требуется файл credentials;
- JSON-статистика и её миграции удалены по запросу пользователя, используется SQLite;
- таблицы цен имеют исходные приближения, включая оценку неизвестных моделей;
- существующие `handleWebSocket`, `serveRequest` и `proxyHTTP` в OCM остаются
  длиннее ориентира 40 строк; дальнейшее разделение этих сценариев не выполнено;
- каталог зависит от версии и доступности Codex backend; запросы к реальному
  OAuth backend в рамках этой доработки не выполнялись.

Эта сверка относится к переносу протокола и каталогу моделей. Она не означает
полного аудита всех сценариев учёта usage и параллельных WebSocket-запросов.

Самопроверка изменённых файлов: новых заглушек UNKNOWN/OTHER, широких
обработчиков ошибок, скрытых подстановок некорректных значений и повреждённой
кириллицы не найдено. `map[string]json.RawMessage` используется только на
границе JSON для сохранения неизвестных полей каталога. Возвраты `nil, err`
соответствуют контракту ошибок Go; `nil` в callback WebSocket означает успех.
